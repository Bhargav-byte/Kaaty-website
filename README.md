# Kaaty Landing Page

Modern landing page for Kaaty, built with React + Vite.

## Live site

https://kaatysaas.netlify.app/

## Requirements

- Node.js 18+
- npm 9+

## Local development

```bash
npm install
npm run dev
```

Vite will print the local URL (usually http://localhost:5173).

## Production build

```bash
npm run build
```

The production output is in the `dist/` folder.

## Netlify (manual deploy)

1) Run `npm run build`
2) Drag and drop the `dist/` folder into https://app.netlify.com/drop

## Deployment note

The production site is already deployed at https://kaatysaas.netlify.app/.
